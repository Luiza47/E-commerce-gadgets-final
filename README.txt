TECHSTORE — COMO PUBLICAR NO GITHUB PAGES

Arquivos:
- index.html
- style.css
- script.js

Os três arquivos devem ficar juntos na raiz do repositório (sem pastas).

Para publicar:
1. Envie os três arquivos para a raiz do repositório no GitHub.
2. Abra Settings > Pages.
3. Em Build and deployment, escolha Deploy from a branch.
4. Selecione a branch main e a pasta /(root).
5. Salve e aguarde a publicação.

O arquivo inicial precisa se chamar exatamente index.html.
